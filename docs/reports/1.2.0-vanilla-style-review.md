## Findings and changes

| Finding | Implemented refinement |
| --- | --- |
| Copper, iron, steel and stone shared conspicuous diagonal streaks, making different materials look alike. | Authored separate 16×16 pixel clusters and restrained palettes for cast iron, worked copper, steel, mortar stone and pale pestle stone. Compared density and contrast against the local Minecraft 1.20.1 workstation textures and native side-by-side scenes. |
| Furniture looked like uniform horizontal bars; plank joints wrapped around small handles. | Added staggered plank joints and broken grain to furniture, and a separate continuous-grain `apparatus_wood` material for tool shafts and small wooden fittings. Static and moving pestles use the same handle material. |
| Paddle blades stood vertically on diagonal shafts, giving the item a bent silhouette. | Aligned each blade, ferrule and shaft on one diagonal; retained distinct wooden and iron construction. Updated the matching slot hint. |
| Some preparation tiles had rectangular liquid edges, detached crystal pixels and decorative stripes unrelated to processing. | Rebuilt liquid menisci, connected crystal clusters and soft-material stages. The stages retain distinct coarse-to-refined silhouettes. |
| Stacked transparent bottle boxes produced internal caps, square shoulders and seams; the splash neck could disconnect from its lip. | Built one continuous chamfered flask outline with joined shoulders and neck, connected splash offset, a contained liquid volume and flat highlights. Strengthened the neck/lip contrast after inspecting shelf-distance captures. Exact vanilla bottle types use these shapes; custom potion subclasses retain their actual item models. |
| The kettle feed stopped below its crossbar; the Alembic's funnels appeared solid or narrowed toward their mouths. | Connected the feed fitting and made the charge/coolant funnels visibly open, with a dark interior, stem and four rim walls. Interaction volumes remain at their existing locations. |
| Most of the firebox grille texture fell outside the model's sampled UV band. | Moved the grille to the four texture rows sampled by the firebox's front face, in both lit and cold states. |
| A crossed effect plane had a normal opposing its winding; tiny glass highlights used unnecessarily layered boxes. | Corrected the plane normal and rendered glass glints as flush surfaces. Bottle sections have caps only at exposed ends. |
| Flat, one-pixel panel borders lacked the depth of vanilla containers. | Gave shared gray panels stepped corners and layered bevels, retaining their content rectangles and accessibility palettes. |
| Working guidance covered the burner or bottle rail at large GUI settings. The camera always reserved 11% of the frame, regardless of GUI scale. | Placed bounded guidance above the vanilla HUD and fitted the apparatus around an 80-logical-pixel footer, with the existing minimum reserve. GUI-scale changes now invalidate the camera fit. Added a projection regression covering all stations, four facings, four aspect ratios and four logical heights. |
| Detailed guidance always displayed the full control legend, including after pressing “H hide.” | Keep numeric readings and a short controls reminder visible; show the full legend only while help is enabled. Capture expanded and collapsed states at the minimum GUI size. |
| The eye-level forearm expanded into an oversized wedge. | Moved its off-screen sleeve anchor from 20% to 65% of the work depth. The hand stays on the actual grip, with its existing skin UV scale; the foreground sleeve has less perspective distortion. |
| Compact Notebook content started underneath its search field, hiding the first row. | Derive the recipe/reagent viewport top from the actual field bottom plus padding. Added live checks that the viewport clears the field, for populated and empty results. |
| Unmatched Notebook searches produced an unexplained blank page. | Added an empty-state message in all five languages and extended visual captures to cover populated and unmatched recipe/reagent searches. |

## Dense-workshop measurements

Each scene uses a 60-second sample after warmup. The baseline is the saved run at the start of this pass, on the same Intel UHD Graphics / i7-13700HX host, Mesa driver, Java 17, fancy graphics, particles All, 12-chunk view distance, default resource pack, 1280×960 window, VSync off and 120 fps cap. This is one local comparison. The harness records measurements and validates scene state; it does not enforce a performance threshold.

The instrument's `level_cpu` value is elapsed time between `AFTER_SKY` and `AFTER_LEVEL`, including possible driver waits. Allocation is render-thread bytes per sampled frame. Frame intervals include the cap and GPU waits.

The 32-kettle and 128-rack samples used about 0.6% and 0.9% more render-thread allocation per frame, respectively. Both world-render p95 values were lower in this run. Frame-interval p95 was 10.302 → 10.196 ms for 32 kettles and 10.302 → 10.204 ms for 128 racks. These samples show no frame-time increase on this host; they do not isolate the visual changes from run-to-run driver and scheduling variation.


## Limits

The runtime matrix uses one local Forge client and integrated server with JEI/Jade, the default resource pack and no shaders. Its observer uses a server-side test player, not a second real client. Standard/slim skin support remains in the rendering paths, but both skin models and arbitrary custom sleeves are not separately certified. Language checks cover rendering and containment, not native-language editorial review. The host cannot load the native `flite` narrator library, so narrator audio is not validated; some client logs also contain OpenAL shutdown errors without a mod crash. Journey footage is inspected through extracted frames and transfer sequences, not continuous human playback. Dense timings are a local diagnostic comparison, not a general performance guarantee. No commit, publication or release is part of this work.
