# Visual refinement of the 1.2.0 workshop

This is the first pass's record. The [follow-up vanilla-style review](1.2.0-vanilla-style-review.md) records subsequent refinements and current validation; the shared November documentation screenshots have been refreshed again for that pass.

Implemented against the existing, uncommitted close-up workshop tree on 13–14 November 2026. This pass refines presentation and inventory layouts; the version and release state are unchanged. Existing overhaul work was preserved. The pre-refinement snapshot and original visual review are recorded in `/tmp/immersive-brewing-polish-20261113-224603/before/` and `/tmp/immersive-brewing-visual-review-x_090_h7/review.md`.

## Changes

- Redrew the 56 original 16×16 material, item, preparation, signature and slot-role textures in the deterministic art source. Copper shares a palette across stations; iron, stone, wood, pale pestle stone, ceramic and paper have restrained, connected marks. Added twelve material/effect tiles. The shipped logo now derives from the existing small project icon.
- Reworked the kettle footing/rim/crossbar, mortar cavity and pestle, and alembic hood/footing. The condenser coil and valve wheel use connected segments. Inventory transforms give the intricate station items more room. Visible controls retain the existing interaction locations.
- Unified dynamic materials, face shading and texture scale. Bottles share a wider flask body, shoulders, neck/lip, stopper and sparse glass highlights in the kettle, alembic and rack; splash/lingering have distinct shapes. Unsupported custom containers retain their actual item models. Distant kettle/rack stock uses native item models after ten blocks.
- Matched paddle and pestle construction between item and live views. One presentation owner per player's working hand prevents outgoing transfers from duplicating a newly held tool's arm. The working arm enters from outside the viewport and ends at the transformed grip, with the player's skin, sleeve setting and slim/classic UV layout.
- Replaced rectangular reaction overlays with authored bubble, ripple, foam, flame, shard, flake and spark masks. Surface effects clip to the vessel opening; streams use crossed planes; mortar material colors come from the ingredient profile.
- Reflowed kettle, rack, mortar and carrier inventories into separate slot/control/text bands. Kettle slot hints now account for all six reagent positions. Captions stay with their slots, and buttons stay inside the panel. Alembic comparison text wraps and scrolls, and follows the job's current state, showing actual waiting output after completion.
- Gave the Notebook a restrained paper/leather treatment, illustrated station cards and readable compatibility results. Journal/Favorites selections measure their wrapped height and use light text on dark selections. The planner has ingredient icons, one relevant operation action and optional advanced detail. Its compact route viewport stays clear of the page switch, hidden list rows cannot display tooltips over the route, and the selected recipe survives page switches and resizing. Routes exceeding the existing Favorites key limit show a disabled star with an explanation instead of reaching the packet encoder. Favorites controls use two rows; narrow actions use short labels with complete tooltips, and entry navigation uses arrows with localized narration. Label editing has a real preview and length feedback; notices use spaced cards.
- Reduced repeated working-view guidance, quieted hover outlines to corner brackets, put rack labels on plaques, and shortened Jade's default summary with Shift for detail. Detailed HUD readings and key help use separate columns beneath a short tool header, including the minimum UI size. Existing large accessibility outlines and presentation palettes remain available.

Implementation sources: [deterministic pixel art](../../art/brewing_art.py), [generated models](../../tools/generate_data.py), [shared material/effect rendering](../../src/main/java/com/otectus/immersivebrewing/client/render/RenderBits.java), [bottles and working arm](../../src/main/java/com/otectus/immersivebrewing/client/render/ApparatusBits.java), [planner](../../src/main/java/com/otectus/immersivebrewing/client/screen/KettlePlanScreen.java), [Notebook](../../src/main/java/com/otectus/immersivebrewing/client/screen/NotebookScreen.java), and [working-view HUD](../../src/main/java/com/otectus/immersivebrewing/client/workshop/WorkshopScreen.java).

## Visual acceptance

The review covered every authored tile, the four apparatus models and moving parts, item silhouettes, bottle/container variants, inventory screens, plan routes, Notebook tabs, notices, labels, tooltips, JEI, Jade and the working-view HUD. Day/night reference scenes placed the stations beside vanilla workstation blocks. The main defects and the resulting acceptance checks were:

| Original defect | Refinement and observed result |
| --- | --- |
| Repeated cross-shaped marks and arbitrary stripes | Replaced by restrained, irregular marks appropriate to copper, iron, stone, wood, paper and ceramic. Shared palettes and model-scale UVs keep stationary and moving parts related. |
| Disconnected or ambiguous silhouettes | Stepped rims/feet, a heavier mortar cavity, broad paddle blade, connected coil/valve, consistent pestle and flask construction. Checked in working and ordinary world views. |
| Rectangular effects and floating/glassy artifacts | Authored transparent masks, clipped liquid decals and sparse highlights. Streams and flame silhouettes remain visible from more than one angle. |
| More than one arm during transfers | One rendering owner per player/frame and explicit transfer/tool arbitration. Twelve closely spaced frames around the dose-to-paddle handoff show one arm attached to the current grip. Left-handed and tools-only views were also inspected. |
| Labels outside panels, buttons over slots, missing sixth reagent hint | Dedicated slot/control/text bands and shared role mapping. Runtime assertions check actual slot rectangles, widget containment and title/inventory separation. |
| Dark text on selected journal rows; clipped long entries | Measured wrapping and high-contrast selection text. Populated journal/Favorites were inspected in all five languages. |
| Long routes obscured by controls or lost when switching pages | Separate scrolling viewport; selection retained by route identity. The five-step route stays selected and scrolls to its final requirements at minimum UI size. |
| Completed Alembic still presented an empty-input prompt | Completed view reads actual output slots, presents the waiting result and omits the idle instruction. |
| Detailed HUD text overlapped hand help | Bounded readout/help columns below the short tool header; both compact and wide high-contrast captures are clear. |

## Dense-workshop measurements

The five scenes each use a 60-second sample after warmup. The baseline is the pre-refinement run saved before this pass; the final run uses the refined assets and renderer on the same Intel UHD Graphics / i7-13700HX host, Mesa driver, Java 17, fancy graphics, particles All, 12-chunk view distance, default resource packs, 1280×960 window and 120 fps cap with VSync off. This is a single local comparison, not a benchmark across systems. The dense pass verifies the scenes and measurements; it does not enforce a performance budget.

World-render timing is the elapsed interval from `AFTER_SKY` to `AFTER_LEVEL` (the instrument calls it `level_cpu`); it can include driver waits. Allocation is render-thread bytes divided by sampled frames. Frame intervals also include the cap and GPU waits, so they should not be read as isolated renderer cost.

| Scene | Before world-render p95 (ms) | Refined p95 (ms) | Before allocation (KiB/frame) | Refined allocation (KiB/frame) |
| --- | ---: | ---: | ---: | ---: |
| 0 kettles | 0.623 | 0.544 | 153.6 | 143.2 |
| 1 kettle | 0.857 | 0.903 | 193.8 | 189.7 |
| 8 kettles | 1.989 | 2.374 | 495.8 | 548.8 |
| 32 kettles | 4.939 | 6.126 | 1629.2 | 1874.8 |
| 128 racks | 4.390 | 5.157 | 2973.7 | 2677.3 |

The first refined 32-kettle run used 1998.9 KiB/frame. The final helper avoids temporary point/UV arrays per sprite and reuses texture identifiers while still resolving sprites against the current atlas; the repeat measured 1874.8 KiB/frame. The richer geometry and effects retain the cost shown above. Frame-interval p95 for 32 kettles was 11.904 → 10.302 ms; for 128 racks it was 11.997 → 10.302 ms. These measurements describe this host and scene, rather than a general performance guarantee.

## Limits

Runtime checks use one local Forge client and its integrated server with JEI/Jade and the default resource pack. The observer journey uses a server-side test player; it does not validate another real client's player-body/arm rendering. The arm UV paths support standard/slim skins, but both skin models and arbitrary custom sleeves were not separately exercised. Some client logs contain OpenAL buffer-timeout messages; no mod crash accompanied them. No shader/alternative renderer, optional potion-mod matrix, native-language editorial review or human usability playtest is claimed. Video review uses extracted frames and handoff sequences, not continuous human playback. Historical October showcase images retain their capture dates; refreshed November captures are identified in the screenshot manifest.

The build is `build/libs/immersive-brewing-1.2.0.jar` (SHA-256 `83892c74c3983da07a9b9241d69b60dc370475e15d4e705b1d3d3923d056ec25`). Nothing was committed, published or released.
