# 1.1.1 visual and interaction overhaul

This development report records the implementation state of the 1.1.1 presentation overhaul. It is not release evidence.

## Implemented packages

- **VIS-02/03:** compact station snapshots/protocol 4, typed station presentation, lifecycle state cues, shared presentation policy, semantic palette/large markers, Access controls, and compact screen geometry.
- **VIS-05–07:** authored five-family mortar material tiles, shared eleven-signature kettle motifs, server-supplied accepted-stage tints, and Alembic run-progress versus collected-volume presentation. Reclamation remains visually distinct from purification.
- **VIS-08–10:** compact result/route plan pages, slot-role labels/icons, staged-preview feedback, compact Notebook chapter control, rack reservation plaques, carrier mismatch wording, concise results, expanded potion details, pinned HUD rows/overflow, and accessible station-notice history.
- **VIS-11/12 foundations:** presentation policy is consumed by renderer/effect code; snapshot/event protocol is strict and observer effects are bounded. Spatial sound/renderer behavior remains subject to live validation.

## Behavior retained

Presentation consumes authoritative snapshots and accepted outcomes; it does not alter recipe eligibility, transaction guards, scores, exact stacks, recovery, or server validation. Animation intensity zero leaves direct state/gauges usable. Reduced motion uses still state rather than autonomous motion.
