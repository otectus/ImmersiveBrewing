# Art and audio sources

The in-game textures and sounds in Immersive Brewing are generated by the code in this directory. Nothing is copied, traced or
sampled from Minecraft, from another mod or from any third-party asset pack, so the assets are original work and part
of the mod under the same licence, GPL-3.0 (see `../LICENSE`).

| File | Produces | Rebuild | Check |
| --- | --- | --- | --- |
| `brewing_art.py` | The 16×16 block and item textures in `src/main/resources/assets/immersive_brewing/textures/` and `logo.png` | `python3 tools/generate_textures.py --write` | `python3 tools/generate_textures.py --check` |
| `brewing_audio.py` | The Ogg Vorbis sounds in `src/main/resources/assets/immersive_brewing/sounds/` and `sounds.json` (with subtitles) | `python3 tools/generate_sounds.py --write` | `python3 tools/generate_sounds.py --check` |

Both generators are deterministic: the same code always produces the same bytes, so `--check` compares the committed
files with a fresh build and fails on any difference. Textures need Pillow; sounds need NumPy and `ffmpeg` with
`libvorbis` (the encoder settings are fixed in `tools/generate_sounds.py` so the output is bit-exact).

Pixel art follows the vanilla look: a 16×16 grid, a small hand-picked palette (gray stone, warm wood, iron, oxidised
copper, clear glass) and no gradients beyond what the palette allows. Sounds are synthesised from noise, filtered
tones and envelopes (bubbles, grinding, glass, valves, drips).

Block models are built from boxes in `tools/generate_data.py` and use only these textures.

The project listing icon lives at `../project-icon-128.png` (128×128 source) and `../project-icon.png` (512×512 export),
matching the sister mods' filenames and 32-color pixel-art style. Its kettle, paddle and burner artwork was created
with the built-in image generation tool using [this prompt](project-icon-prompt.txt), then reduced to 128×128 with
nearest-neighbor sampling and quantized to 32 colors without dithering. Rebuild the export with
`python3 tools/generate_textures.py --project-icon --write`; verify it with
`python3 tools/generate_textures.py --project-icon --check`. The export uses Pillow's `Image.Resampling.NEAREST`,
so each source pixel becomes one solid 4×4 block with identical color and alpha, without smoothing or antialiasing.
